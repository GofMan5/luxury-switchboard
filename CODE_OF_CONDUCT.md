# Code of conduct

Be useful, be honest, don't be a jerk.

**The short version.** This is a tool for people who run their own infrastructure. Disagree about code as hard as you like; attack the code, never the person. Assume competence and good faith until proven otherwise, and extend both once more after that.

**What we expect:**

- Technical criticism is welcome and should be specific. "This breaks X" beats "this is bad".
- No harassment, slurs, personal attacks, or dogpiling. Zero warnings for the obvious cases.
- Provider names, keys and endpoints you use are yours to keep: never post someone else's credentials or traffic, and never demand that others expose theirs.
- Marketing language does not belong in issues or PRs. The project's bar is honest states and measured claims; conversation holds the same bar.

**Enforcement.** Violations get one warning from a maintainer for honest mistakes, none for the obvious cases. Repeated or severe cases end in a block. Report privately through [GitHub Security Advisories](https://github.com/GofMan5/luxury-switchboard/security/advisories/new) only if the report itself carries sensitive data; otherwise an issue is fine.

**Scope.** This repository: issues, PRs, discussions, and any space the project operates.
